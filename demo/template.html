The method

A turbine is a shadow with an alibi

At 10 m per pixel a wind turbine is not an object — it is a smear. What survives is geometry: a thin dark blade of shadow thrown exactly where the sun says it must fall, ending in a bright nacelle sitting exactly where the satellite's viewing angle says the hub must be. The detector never learns what a turbine looks like. It asks how unlikely this particular arrangement of dark and bright pixels would be in an image with no turbine in it.

Run it on your own scene

# build the page and open it, with the detector live behind it
python3 -m venv .venv
.venv/bin/pip install -r demo/requirements.txt
.venv/bin/python demo/turbine_demo.py --serve

# any single-band Sentinel-2 GeoTIFF plus its sidecar
.venv/bin/python demo/turbine_demo.py \
    --image example/test.tif \
    --meta example/test_meta.txt \
    --heights 60,80,100 --t-nfa 1 --serve

Every run also writes detections.csv and detections.geojson beside the page, so the candidates drop straight into QGIS.
